# Велоарсенал

Подбор велоэкипировки по погоде. Погода берётся с Open-Meteo при запуске и каждые 15 минут; город ищется по названию или определяется по местоположению.

Своя одежда добавляется во вкладке «Вещи»: слот, тип и материал. Подбор называет, что нужно надеть (например, «ветровка» или «снуд на нос»), и подставляет подходящую вещь из инвентаря; если её нет — замену или подсказку, что искать. Инвентарь хранится только в браузере или приложении, его можно выгрузить в файл и загрузить обратно.

- `docs/index.html` — сам Велоарсенал (одна страница, без сборки)
- `macos/main.swift` — окно macOS с WebKit, которое показывает страницу
- `macos/Info.plist`, `macos/icon.png` — описание и иконка приложения
- `private/inventory.json` — личный список вещей (не в git); `build.sh` подставляет его в приложение как стартовый инвентарь

## Сборка

```bash
./build.sh --open
```

Собирает `build/Велоарсенал.app`, ставит в `~/Applications` и запускает. Нужен `swiftc` (Xcode Command Line Tools).

Страницу можно открыть и просто в браузере: `open docs/index.html`.
